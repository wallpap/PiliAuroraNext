# 社区模块

动态作者与分类、小站、评论与直播表情、投票和预约编辑由本模块管理。查询与写入位于 `application/`，显式账号的 HTTP 适配位于 `data/`，协议与草稿位于 `domain/`。共享异步约定见[状态管理](../../../doc/development/state-management.md)。

## 动态

作者查询按页面实例与主账号对象身份隔离，临时屏蔽和作者选择属于主账号会话。作者游标读完后按偏好读取普通关注，统一按 MID 合并资料并保留已读标记和未读排序；重复游标结束该阶段，连续无增长补读有预算，失败保留原位置。

分类查询包含页面、类型、作者与账号。分页失败不推进游标；删除按动态 ID 互斥，确认成功后同步订阅分类，并排除在途页中的同 ID。发布与转发通过领域失效信号刷新，展开只修改当前快照的折叠状态。

Widget 持有 Tab、滚动和展开状态，分类通过构造回调注册窄句柄。父页刷新等待作者与当前分类，句柄按身份注销，页面之间不反查业务 controller。

## 小站

查询键包含页面、小站、分类和排序，路由显式传入资源 ID。目录与列表同轮发布，续页保留目录，目录替换释放旧 Tab 子树。滚动由 Widget 持有，实际视口触发分页；切换分类保留各自位置，重复点击当前分类回顶，失败保留原页码并允许重试。

## 表情

评论包按面板实例与主账号隔离，直播包另绑定房间；请求沿查询捕获的账号发送。Tab 随包快照释放，编辑器和发送面板只消费选择或发送意图。

最近表情是应用级可选缓存，去重、限长、复制调用方内容并串行保存。损坏记录逐条跳过，缓存失败不影响选择。普通图片表情保留惰性网格与图片视口需求，管理页拥有自己的编辑状态。

## 投票与预约

`AccountDraftEditor` 固定打开时的主账号，按页面实例和资源 ID 持有草稿；账号替换停止旧编辑。详情同时校验请求代次与草稿版本，期间的新输入保留，需主动刷新核对。

保存固定不可变提交快照并互斥，成功采用返回 ID，允许继续编辑同一远端对象。上传按稳定选项和操作身份回写，删项或重选图片后旧结果失效。页面持有输入、选择器、导航和提示；参数替换或关闭后，旧结果不能关闭新页面或覆盖新输入，临时文件仍由原操作清理。

## 验证

领域测试在 `test/features/community/`，页面回归按 `test/pages/` 下的动态、小站、表情和发布入口定位，HTTP 适配在 `test/http/` 验证。测试选择与夹具见[测试目录](../../../test/README.md)。重点检查多页面、同 UID 换凭据、乱序详情与上传、分页重试、写入待确认和活动 Tab 释放。真实服务、表情权限、原生输入与 Android/Windows 滚动需设备验收。
