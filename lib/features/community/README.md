# 社区模块

动态查询、互动、发布、话题与发布选择、小站、表情和投票/预约编辑由本模块管理。查询与写入位于 `application/`，显式账号的 HTTP/gRPC 适配位于 `data/`，游标、协议与草稿位于 `domain/`。共享异步约定见[状态管理](../../../doc/development/state-management.md)。

## 动态

作者查询按页面实例与主账号对象身份隔离，临时屏蔽和作者选择属于主账号会话。作者游标读完后按偏好读取普通关注，统一按 MID 合并资料并保留已读标记和未读排序；重复游标结束该阶段，连续无增长补读有预算，失败保留原位置。

列表查询复用 `DiscoveryListing` 的账号归属、刷新、去重和分页状态。各入口的查询键与操作在以下文件中维护：

| 入口 | application 入口 | 查询范围 |
| --- | --- | --- |
| 动态分类 | `dynamics_feed.dart` | 页面实例、分类、作者与主账号 |
| 空间动态 | `member_dynamics.dart` | 页面实例、空间 MID 与主账号 |
| 点赞与转发名单 | `dynamic_activity.dart` | 页面实例、动态 ID、名单类型与主账号 |

分页失败保留原游标；重复游标结束，连续无增长补读有预算，耗尽后由用户显式继续。空间接口每次读取一页，后续调度归查询所有者管理。分页由实际视口触发，构建末项不发请求。同账号刷新保留已确认内容和滚动，首包成功后替换，失败提供重试；换凭据立即隐藏旧账号的列表与计数。

`DynamicsActions` 按账号对象身份持有删除与置顶的写入锁。相同动态的删除互斥；置顶与该账号的删除互斥。锁保留到请求完成，刷新、页面释放或重新打开均不能提前解锁。确认删除通知分类、空间和话题列表，并排除在途响应中的同 ID；置顶结果同步当前账号的空间实例，保留普通标签，迟到分页沿用已确认状态。显式刷新重新核对服务端。

空间管理操作校验当前空间属于主账号，确认菜单绑定原查询与条目，刷新或换凭据后旧回调失效。远端确认成功仍交付成功，当前订阅者继续接收领域通知；旧页面不再弹提示。写入失败或待确认保留列表，用户可刷新核对。

Widget 持有 Tab、滚动和展开状态，分类通过构造回调注册句柄。父页刷新等待作者与当前分类，保留动态卡片和作者面板；重复点同一作者时回顶并刷新，换作者时从顶部打开。句柄按身份注销。发布和转发通知已订阅列表刷新，展开只修改当前快照。

点赞与转发名单的标题订阅不启动请求，首次进入 Tab 激活查询。计数随名单和游标同轮确认；同账号刷新保留旧计数，换凭据后重新读取。重复点击当前 Tab 刷新或回顶、横屏下拉刷新沿用详情页交互。`dynamic_activity_repository.dart` 负责 gRPC 请求、分页解码和名单投影，页面消费作者资料和结构化转发内容。

`DynamicDetails` 提供详情读取、链接解析、匿名可见性检查和管理操作。每个详情页持有自己的滚动和评论来源适配器。写入锁按账号对象与动态或评论目标隔离，关闭后重新打开同一详情仍须等待在途写入。动态卡片和文章页共用 `DynamicsActions` 的点赞锁，按账号对象与动态 ID 隔离。只在确认成功后更新原入口的状态，换凭据后不回写。应用的 Riverpod 作用域持有 `DynamicsUpdates`，供发布、管理和列表共享失效事件，作用域释放时关闭广播。

发布、编辑和转发使用 `DynamicsPublishing`。提交前捕获草稿和账号，图片上传结束后再次检查归属，本次提交期间的新输入仍留在表单里。确认发布或编辑后通知同账号的列表刷新，失败和待确认保留草稿。页面管理输入、上传取消、提示及关闭表单，编辑同一动态时共用写入锁。

## 小站

查询键包含页面、小站、分类和排序，路由显式传入资源 ID。目录与列表同轮发布，续页保留目录，同账号、同查询且分类 ID 未变的刷新保留 Tab 与滚动；账号、查询或分类 ID 变化时释放旧 Tab 子树。滚动由 Widget 持有，实际视口触发分页；切换分类保留各自位置，重复点击当前分类回顶，失败保留原页码并允许重试。

## 话题与发布选择

`topic_queries.dart` 管理推荐话题、话题内容、话题搜索和提及用户查询。推荐话题与话题内容沿用推荐账号；话题头部、话题搜索和提及用户绑定主账号。内容查询另订阅主账号以隔离屏蔽规则，头部由 `topic_header.dart` 按话题 ID 共享。页面通过构造参数接收话题 ID，页面实例与排序隔离内容查询。

内容页复用发现列表的刷新、过滤、视口分页与失败重试约定。排序随响应确认，续页缺少排序目录时保留已确认目录；重复游标停止分页。展开绑定查询代次，在最新快照中替换占位项并保留并发续页，刷新后旧展开不占用新操作。发布与删除沿用动态失效信号。

点赞按账号身份与话题互斥，离页后锁保留到请求结束；确认成功通知当前订阅者核对。收藏复用 `FavoriteLibrary` 的写入锁和失效通知。头部刷新保留已确认内容，失败提供重试；写入只修改所属快照，刷新或切号不改变已确认的远端成功结果。导航、举报、分享及提示由页面消费，并检查页面和账号归属。

话题与提及选择面板拥有独立查询、输入、焦点和滚动，输入变化立即使旧结果失效，网络请求防抖。清空立即重查，搜索回顶，话题分页失败保留原页供重试。编辑器通过 `CommunityPickerMemory` 保留搜索与未确认选择，面板释放不遗留请求订阅；重开后补齐恢复滚动位置需要的分页。提及按 UID 选择，行点击返回单项，确认返回独立集合；换凭据清除旧选择，旧面板结果不能写入新账号编辑器。

## 评论

独立评论页、视频、动态、文章、音乐和赛事共用 `Comments`。宿主提供评论目标和初始计数；视频在评论面板打开时查询，文章和音乐等到详情给出目标后再查询，赛事可直接用路由中的 CID。课堂视频保留已有接口参数：读列表用课节 ID，发顶层评论和置顶用视频 AID。

评论查询按页面实例、目标和登录凭据隔离。主列表、楼中楼和对话使用各自的 gRPC 接口，排序和刷新重新起算游标。每次最多补读五页；遇到失败保留已取得的内容和游标，用户可以继续加载。数据适配器将列表、发布回显和翻译转为社区评论模型。楼中楼的定位高亮、滚动和弹层由 Widget 管理。

确认拉黑后，同账号的主列表、置顶、楼中楼和对话按 UID 局部更新缓存，保留分页游标和服务端计数。新加载和在途回包使用当前黑名单过滤。

`CommentInteractions` 按目标保留编辑草稿。刷新列表不会丢草稿；换凭据或改目标后，旧编辑器的结果不能回显到新页面。发布沿用服务端返回的回复确认回显位置；没有回显内容时重读列表。置顶只在服务端确认后调整列表。

评论附件搜索分别查询视频和专栏。页面持有输入、提交词、Tab 和滚动位置；两类查询共用提交词，按页面提交代次与主账号凭据隔离。只在可见视口需要时续页，失败可重试原页；关闭选择页释放查询。gRPC 适配将搜索结果转为附件展示数据，点选仍返回标题与 URL。

「我的评论」从 `SavedReplies` 读取本机归档，复用评论卡片的互动。适配器保留已有二进制归档和 JSON 导入导出格式，列表按发布时间排序。删除回执按评论 ID 更新当前列表，导入导致位置变化时仍更新对应条目。

Windows 上可右键评论配图或打开大图后右键，选择「复制图片」。静态图可直接粘贴为图片；GIF、动态 WebP 和 APNG 保留原文件，可粘贴到支持文件粘贴的应用，是否播放动画取决于接收应用。

协议分页、回显和编辑器测试见 `test/pages/video/reply/` 和 `test/pages/community/`。动态、文章、音乐及赛事的目标解析也有独立测试。

## 视频笔记

`videoNotesProvider` 按面板、视频和主账号隔离列表与总数，匿名可读，编辑入口仅对已登录账号显示。分页由视口触发，按笔记 ID 去重；失败保留已读内容，重试原页。视频面板保留原阅读与 WebView 编辑入口。

## 影视点评

`PgcReviews` 按面板、作品、长短评和主账号查询，排序替换游标，重复游标停止。`PgcReviewWrites` 让同账号对同一点评的赞、踩、编辑和删除互斥；只将已确认且仍属于当前列表的结果回显。草稿、星级和长评 WebView 入口由页面持有。

## 表情

评论包按面板实例与主账号隔离，直播包另绑定房间。评论面板重读后按包 ID 恢复选中项，原包不在时将索引限制在新列表范围内。换账号后按初始规则选中页签。

最近表情是应用级可选缓存，去重、限长、复制调用方内容并串行保存。损坏记录逐条跳过，缓存失败不影响选择。普通图片表情保留惰性网格与图片视口需求。`EmoteManagement` 按页面和主账号持有分类结果与包级写入锁；仅确认成功才变更已添加列表，换凭据或离页停止旧分类翻页。预览按账号和包 ID 加载，搜索与展示留在页面。

## 投票与预约

`AccountDraftEditor` 固定打开时的主账号，按页面实例和资源 ID 持有草稿；账号替换停止旧编辑。详情同时校验请求代次与草稿版本，期间的新输入保留，需主动刷新核对。

保存固定不可变提交快照并互斥，成功采用返回 ID，允许继续编辑同一远端对象。上传按稳定选项和操作身份回写，删项或重选图片后旧结果失效。页面持有输入、选择器、导航和提示；参数替换或关闭后，旧结果不能关闭新页面或覆盖新输入，临时文件仍由原操作清理。

## 验证

领域测试在 `test/features/community/`，页面回归按 `test/pages/` 下的动态、小站、表情和发布入口定位，HTTP 适配在 `test/http/` 验证，点赞与转发名单的真实 gRPC 请求在 `dynamic_activity_test.dart` 验证。测试选择与夹具见[测试目录](../../../test/README.md)。重点检查多页面、同 UID 换凭据、乱序详情与上传、分页重试、写入待确认和活动 Tab 释放。架构测试约束动态查询、管理、互动、发布和名单请求的传输入口。真实服务、表情权限、原生输入与 Android/Windows 滚动需设备验收。
