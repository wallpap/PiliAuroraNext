# 个人空间

`MemberPage` 根据空间响应生成首页和投稿栏目。主 Tab、投稿 Tab 和嵌套滚动由页面管理。首页的「查看更多」通过回调选择投稿栏目；Web 投稿入口根据当前栏目决定打开普通投稿、合集还是系列。

`MemberSpace` 按页面实例、MID 和 `from_view_aid` 查询；同一 UID 的凭据替换也会使旧快照失效。关系操作、预约及经验领取只接受发起操作时的账号。确认框、提示和跳转由页面消费，刷新或离开后不再交付旧结果。

普通投稿使用 AID 游标；「定位至上次观看」既能定位已经加载的卡片，也能请求锚点附近的投稿。从列表头加载上一段时，页面保留原有浏览位置。充电投稿、合集和系列保留各自的页码或游标。`SpaceWeb` 按路由选择 Web 接口，筛选、排序和跳页替换查询；旧跳页弹窗不能改新列表。「播放全部」和「继续播放」在确定播放目标后再交给导航。

收藏和订阅分开分页，仍由「查看更多内容」触发。同一分区不能重复加载同一页；删除收藏夹后重读首屏，因为远端偏移已变化。作品和追番沿用发现列表的视口分页与重试约定。

相关测试在 `test/pages/member/`、`test/pages/member_favorite/` 和 `test/pages/member_pgc/`。嵌套滚动、观看定位和原生播放器跳转还需在目标设备上检查。
