# Riverpod 第三轮迁移清单

评估基线：2026-11-17，`dd2e429`。本地 `doc/dev/architecture-critique.md` 为评估输入；本清单记录可跟踪的决策与验收入口。

## 全局判断

本分支已完成下载、稍后再看、历史、收藏、订阅、共享账号资料，以及推荐、热门、排行榜、精选合集、直播发现。已有 `DiscoveryListing`、账号角色 provider、页面滚动句柄、领域写入结果等可复用约定。下一轮应减少遗留协调关系，避免复制 controller 后只替换响应式字段。

| 候选领域 | 当前依赖与收益 | 决策 |
| --- | --- | --- |
| PGC 首页 | 首页壳最后一组按 Get.find 分发的发现列表；推荐、追番、时间表分别绑定不同账号角色 | 第一项，补齐发现模块；三个查询独立拥有生命周期 |
| 动态总览与分类 | 主壳、作者面板、分类列表、卡片屏蔽和发布回调互找 controller | 第二、三项，先拆协调契约，再迁列表与跨入口失效 |
| 小站 | 目录、排序、分页和 Tab 混在同一 controller；子分类依赖隐式路由参数 | 第四项，显式资源键与页面实例，目录快照驱动 Widget |
| 评论与直播表情 | 编辑器主动删除共享 controller，多个面板会争抢状态；Tab 与请求生命周期混合 | 第五、六项，独立面板查询与应用级可选历史；共享领域目录，不合并不同协议 |
| 投票、预约 | 草稿、上传、查询与有副作用的保存混在 GetX；保存必须固定账号并保留失败草稿 | 第七、八项，以同一社区领域承接编辑操作，界面拥有输入和提示 |
| 个人空间 | 主空间、首页卡片、投稿页及子列表存在双向 controller 依赖 | 下一轮按完整空间快照与投稿契约迁移，避免仅搬主 controller 后保留跨页反查 |
| 评论主链与内容详情 | 通用评论基类贯穿视频、文章、音乐、赛事及详情操作 | 需先设计评论查询、排序、投票、写入失效及详情来源接口，作为单独整轮 |
| 播放器、直播房间、音频 | 含原生输出、连接、系统媒体与租约；收益大但设备验收面广 | 独立推进，不与普通查询迁移混合 |
| 登录、设置和主壳 | 凭据写入及平台副作用，主壳仍承担兼容路由和布局 | 本轮仅替换业务 controller 耦合点，后续按账号操作和平台所有权收敛 |

## 执行顺序与验收

每项单独提交，提交前运行直接相关回归；最终运行完整业务静态分析、架构检查及本轮相关回归。状态随对应提交更新。

| 序号 | 模块 | 必须完成的契约 | 状态 |
| --- | --- | --- | --- |
| 1 | PGC 首页 | 推荐账号目录、主账号追番和时间表独立 provider；分页失败重试；部分时间表失败；首页窄句柄；删除旧 controller | 已完成，直接回归 9 项通过 |
| 2 | 动态作者面板与协调 | 主账号作者游标和普通关注补位、已读标记；选择与临时屏蔽有明确所有者；Tab/滚动归 Widget；主壳不创建业务 controller | 已完成，作者与管理、主壳及架构关联回归 50 项通过 |
| 3 | 动态分类信息流 | 页面/类型/作者/账号查询键；游标防重复、过滤补读、失败重试；删除/屏蔽/展开及发布失效；移除互找 controller | 已完成，动态与 HTTP 直接回归 44 项通过 |
| 4 | Bubble 小站 | 页面/小站/分类/排序查询键；目录和列表同轮快照；Tab 释放与真实视口分页 | 已完成，小站与架构回归 24 项通过 |
| 5 | 评论表情 | 面板独立包列表；Widget 持有 Tab；应用级历史限长与串行可选缓存；编辑器不删除其他面板状态 | 已完成，表情、社区编辑器与架构关联回归 70 项通过 |
| 6 | 直播表情 | 房间/面板/账号隔离；请求显式账号；Widget 持有 Tab；发送入口不管理查询资源 | 已完成，表情、直播房间与架构关联回归 85 项通过 |
| 7 | 投票编辑 | 页面独立草稿和固定账号；迟到详情/上传失效；保存互斥和结果交付；失败保留草稿 | 待迁移 |
| 8 | 预约编辑 | 页面独立草稿和固定账号；详情/保存失效；失败保留草稿；文档、架构与 CI 覆盖 | 待迁移 |

所有模块均遵循 `presentation -> application -> data/domain`；页面仅处理用户意图、导航、提示和界面资源。账号按对象身份隔离，同 UID 换凭据也废弃旧结果；刷新、替换查询及释放不允许迟到回写。每项迁移同时替换旧测试入口并增加有意义的生命周期回归，不保留重复的业务状态源。

真实服务、Android/Windows 输入与滚动、表情权限及发布结果仍需目标设备验收；主机测试验证协议适配、状态归属及资源释放。
