# 状态与异步结果

根 `ProviderScope` 在 `lib/app/app.dart` 装配。修改状态前，先确定账号、查询和资源的所有者，再决定订阅与释放位置。源码入口见[功能地图](features.md)，领域内契约随模块维护。

## 所有权

页面查询按页面实例、资源和已提交筛选隔离；输入、选择、Tab、滚动、导航及提示由 Widget 持有并释放。页面间通过构造参数、回调或窄句柄协作。

跨页面共享状态由领域模块或 Session 持有。页面退出只释放自己的订阅或租约；应用级任务在所属作用域结束时关闭。下载、消息及原生播放分别遵循自身的释放协议。

账号按对象身份判断，同 UID 更换凭据也会使旧请求失效。请求与屏蔽规则可能使用不同角色，须分别捕获；仅推荐账号变化时，主账号查询和消息 Session 保持各自生命周期。角色来源见 `lib/services/account_providers.dart` 和 `lib/utils/accounts.dart`。

各领域的共享状态、写入锁和资源边界见[下载](../../lib/features/download/README.md)、[消息](../../lib/services/messaging/README.md)、[账号](../../lib/features/account/README.md)、[内容发现](../../lib/features/content_discovery/README.md)、[社区](../../lib/features/community/README.md)及[内容管理共享实现](../../lib/features/content_library/README.md)。

## 查询与分页

- 刷新、换凭据、替换查询或释放后，迟到结果不回写。多步查询在每个异步边界检查归属，失效后停止后续调度。
- `AsyncValue` 在加载或错误期间可能保留旧 `value`。显示计数、自动分页和写入资格须同时检查 `isLoading`、`hasError`，切号期间隐藏旧账号内容。
- 输入变化在防抖前使旧联想失效。已提交关键词与编辑中的输入分别保存，筛选变更建立新查询。
- 分页串行，失败保留已确认内容和游标，显式重试原页。按领域 ID 去重，游标重复时停止；基于偏移的列表在删除后重读边界，避免前移漏项。
- 过滤补读须有预算。用过滤前的分页信息判断后续页，预算耗尽时明确结束或提供继续入口，具体语义由领域决定。
- 列表及其目录、计数和说明属于同一查询快照。读取失败不以空列表冒充成功，未保存的草稿不修改确认快照。

`FeedPagination` 按实际滚动范围加载，以 `dataSource` 的对象身份隔离来源，`dataRevision` 触发快照检查。来源替换后，新分页不等待旧请求；后台页面是否继续请求由查询所有者决定。

## HTTP 与写入结果

调用方区分成功、失败、取消、无数据和待确认，保留原始原因与堆栈，提示不暴露凭据或响应正文。code/message/data 协议复用 `Request.requestApi`，显式声明 `ApiCallKind`，领域解码器决定可空语义；独立协议保留自身契约。

请求前固定账号，HTTP 凭据与 CSRF 来自同一对象，多步操作沿用该账号。写入关闭网络自动重试，无法确认服务端结果时交付待确认，重试前按业务要求查询核对。

写入按账号、对象或业务互斥，提交时捕获不可变快照。结果返回后分别检查业务归属与界面归属：确认成功后的本地收尾可以继续，提示、关闭弹窗或导航须仍属于原页面。成功写入引发查询失效，不能因此误判已经确认的写入失败。

失败保留草稿与选择；详情或上传结果按请求代次及草稿版本回写，不能覆盖期间的新输入。弹窗、日期和图片选择器也绑定原查询，页面参数替换后旧回调失效。

部分成功保留已确认步骤。远端成功后的缓存、回调或偏好保存失败单独交付；有成本的待确认写入须核对对应字段后才能再次执行。成功写入通过领域信号刷新受影响入口。

## 释放与平台操作

操作所有者消费 Future 的失败，`dispose` 负责停止接收、撤销交付和释放资源。取消或超时不代表已启动的原生工作结束；名额、文件和租约保留到真实完成屏障。旧回调只能清理自身注册，不能移除后来建立的状态。

播放命令的确认、实际观测与用户意图分别建模，约束见[播放状态模型](playback-model.md)。原生截图、音频、WebView 和设备发现按各自协议排空；平台保存开始后，等待文件消费完成再清理临时产物。

## 验证

按[测试目录](../../test/README.md)选择对应领域、页面、HTTP 和服务回归。重点覆盖失败重试、同 UID 换凭据、刷新或离页后的迟到结果、部分成功和资源释放。模拟通道与主机测试覆盖协议，真实服务、输入、WebView、音频和显示行为需目标设备验收。
