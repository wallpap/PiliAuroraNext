根 `ProviderScope` 位于 `lib/app/app.dart`。已迁移入口使用 Riverpod，路由和其他页面沿用现有实现；迁移前明确所有权及释放边界，再移除相应 GetX 注册。源码定位见[功能地图](features.md)。

表中页面入口相对 `lib/pages/`。FocusNode、输入、Tab、滚动控制器、路由与提示由 Widget 持有并释放；Notifier 返回业务结果。页面间使用构造参数、回调或窄信号，不通过 Get.find 互取控制器。

字幕用户底距由播放器控制器保存并发布配置；`PlayerSubtitleView` 只在当前控件可见期间计算临时避让，拖动或设置新位置后以用户值为准。隐藏控件和销毁 Widget 均不回写旧位置。

主账号与推荐账号按对象身份判断。同 UID 的新凭据也会使依赖重建；仅推荐账号变化时保留主账号查询及消息 Session。查询角色须显式绑定：直播搜索、推荐、PGC 目录和索引使用推荐账号，追番、时间表、空间查询、隐私和屏蔽使用主账号；综合搜索的请求与屏蔽分别使用相应角色。

## 查询与分页

首页推荐由 `recommendationFeedProvider` 统一拥有调度。共用账号换凭据时立即撤销旧查询，合并同一轮角色通知后重读；后台换号先隐藏旧内容，返回前不启动请求。App/Web、保留历史和提示偏好直接订阅存储，旧首页壳只使用 Widget 注册的滚动/刷新句柄。

- 输入变化在防抖前使旧联想失效；清空、关闭或禁用联想均丢弃旧结果。提交关键词和筛选生成独立查询，页签计数来自当前有效快照。
- 刷新、切号、替换查询或释放后，迟到结果不回写。`AsyncValue` 错误或加载期间可能保留旧 `value`，显示计数、自动分页和写入资格须同时检查 `isLoading`、`hasError`，切号期间隐藏旧内容。
- `FeedPagination` 按实际滚动范围加载，以 `dataSource` 的对象身份隔离来源，`dataRevision` 触发快照检查；Riverpod 无需额外 stream。来源替换后，新分页不等待旧请求。
- 分页串行，失败保留内容和页码并显式重试。按领域 ID 去重；基于偏移的列表删除后重读边界页，防止前移遗漏；刷新或切号使旧分页失效。
- 动态 UP 面板先读取动态游标，全部关注模式在动态页结束后再读取普通关注页码；按 MID 合并资料，保留本轮已读标记，并将未读作者稳定排在前部。重复游标结束动态阶段，重复作者页按五页预算补位；失败不推进游标或页码。
- 过滤后空页按原始分页信息继续读取，游标重复或连续五页无增长时限界。关注直播优先使用总页数或过滤前总数；综合搜索保留首屏特殊卡片，后续页查视频，分页期间移除的项继续保持移除。
- 订阅隐藏页最多自动补读五页；预算耗尽后保留远端游标并关闭自动分页，由用户显式继续。清理先读取完整订阅快照，避免取消导致偏移前移；页面释放或换凭据后不再调度扫描和写入。
- 共享列表依赖成功快照：规则读取失败不以空列表覆盖播放器，专栏文集不混用旧元数据，分组计数不由未保存的勾选派生。商品无后续游标时保留服务端查看更多入口，充电排行保留首页最多 100 条的语义。

发现列表共用 `DiscoveryListing` 的查询所有者。过滤补读最多五页，耗尽后关闭自动补读并显示继续入口；分页失败保留原页码，重试仍读取失败页。直播总数按过滤前条目累计，顶部与标签在补读期间沿用同轮确认快照。每周必看的目录和详情沿同一推荐账号，多步读取在刷新、切号和释放后停止后续调度；期数和播放列表元数据不跨查询复用。

## HTTP 与写入结果

- 调用方须区分成功、失败、取消、无数据和待确认；保留原始原因与堆栈，提示不暴露凭据或响应正文。code/message/data 协议复用 `Request.requestApi`，显式声明 `ApiCallKind`，领域解码器决定可空语义；独立协议保留自身契约。
- 发现列表同时绑定主账号屏蔽规则与内容查询账号；推荐账号单独切换时丢弃旧响应，后续分页从首页重读。纯主账号动态使用主账号上下文。视频卡片的分 P 查询通过 `PageUtils.openVideo` 固定输入和账号，统一检查来源 Widget 与导航归属，空分 P 显式提示并允许重试。
- 请求前固定账号，HTTP 账号与 CSRF 来自同一对象，多步操作沿用同一账号。写入关闭网络自动重试，无法确认服务端结果时保留 UnknownResult，消息沿用其 unknown 语义。
- 写入按账号、对象或业务串行互斥；异步返回检查账号、目标、查询所有者和页面存活。切号、刷新或离页停止后续步骤，迟到弹窗也失效。
- 评论延迟检查绑定原评论页、账号与来源；发布成功回调早于编辑页关闭，须在打开编辑页前捕获原路由。查询 Future 在结果交付时完成，弹窗自己负责关闭和释放观察者，失效后不再跳转申诉。
- 草稿包含来源、内容和阶段，失败保留草稿或选择。分组、标签、隐私等仅在成功后更新确认快照；来源变化拒绝旧编辑，自己的新建结果可提供继续编辑的确认来源。
- 投票与预约的详情按请求代次和草稿版本校验，加载期间的新草稿保留并要求主动刷新核对。保存固定不可变快照，成功采用返回 ID 后可继续更新；图片上传按稳定选项及操作身份回写，删项和重选图片使旧结果失效。界面交付另检查当前路由和查询，旧保存不关闭后来打开的页面。
- 本地设置入口持有异步保存，输入失败保留草稿；确认落盘后应用运行时状态，应用失败提示已保存。图标保存、原生确认、回滚与启动器同步共用串行边界。
- 部分成功保留已确认步骤，例如弹幕规则删除成功但新增失败。远端成功不被本地清理、回调失败覆盖，Future 的失败由操作持有者消费，dispose 不发写请求。
- 资料改名等有成本的写入待确认时，先刷新核对对应字段再允许后续修改，核对查询须晚于待确认回执发起；刷新替换快照不能解除仍在途写入的核对要求，缺失对应字段也不能当作已核对。已确认的远端修改保留，本地缓存同步失败单独记录。
- 成功写入刷新其他受影响入口，并废弃旧查询；播放器规则只在成功快照变化时同步。资源释放遵循模块协议，消息租约不替换为普通页面状态。
- 下载初始化与创建、删除、启动共享串行边界；读取失败显式交付，不能以空列表表示成功。创建确认落盘后才标记已加入；弹幕更新保留上次可用文件，已取消或被较新来源替换的操作不再回写或提示重试。
- DLNA 页面在 Android API 37+ 先取得局域网权限再启动发现，授权等待期间离页丢弃迟到结果。页面持有发现订阅、超时和设备资源，启动失败或释放后的迟到启动均清理；设备连接串行，setUrl/play 均被接受后才确认选择，原设备暂停失败单独交付部分成功。视频入口先核对账号、分 P 与导航归属；HTTP 接受不等于电视实际播放，设备状态另行验收。
- 音频播放来源查询绑定账号与选曲代次，原生 open 串行，成功回执后确认曲目；失败允许同项重试。动态 WebP 截图持有自己的暂停令牌、加载提示和临时目录，结束仅释放自身令牌，保留用户播放意图；平台保存已开始时，等待文件消费完成后再清理。
- 点播画质/音质/编码及直播线路/画质切换交付 `LoadResult`，加载 ready 后才确认选择和偏好；失败保留确认值并允许重试，离页恢复使用已确认来源。音频列表独立交付初始化与分页状态，切号隔离、分页互斥去重，失败保留游标并显式重试。
- 系统媒体控制按回调是否注册决定归属，音频未就绪时不回退操作底层视频；停止回执只清除原媒体。定时暂停等待命令完成再提示，失败提示手动暂停，取消或重设定时后不发布旧回执提示。
- 音频页控制等待原生命令后确认速度/音量/进度，设置保存失败单独提示；页面入口消费失败，系统控制保留原始 Future 错误。通知回写及释放核对当前回调所有者，旧页面关闭不清新页面的媒体/定时回调。独立音频通过 `IndependentAudioLease` 持有声音归属，接管前等待视频或前一音频暂停，原生 Player 销毁后才交还；系统中断保留播放意图，拔耳机显式暂停，duck 恢复核对音量修订。

## 验证与迁移边界

按[测试目录](../../test/README.md)选择对应页面、HTTP 或服务回归，命令和平台前提见[构建与测试](build-and-test.md#静态检查与测试)。重点覆盖失败重试、同 UID 换凭据、刷新/切号/离页后的迟到结果、部分成功和订阅释放。真实服务、输入、WebView 及播放器显示需设备验收。

稍后再看、历史、收藏和订阅已通过 Riverpod 查询和共享写入 Interface 统一范围内入口失效；共享资料和个人中心归账号领域，推荐和 PGC 归内容发现，动态作者/分类、小站、表情与投票/预约归社区领域。本轮评估与后续边界见[迁移清单](riverpod-next-eight.md)。个人空间、评论主链、登录表单、播放及直播连接继续分别收敛状态和资源生命周期。下载采用应用级 provider 保活，根作用域释放时停止传输，页面离开仅释放订阅。公共抽象由实际重复行为驱动，优先领域内直接 Notifier 与不可变状态。

异常处理按调用链逐模块检查，已验证范围与回归入口统一见[测试目录](../../test/README.md)，不以 HTTP 层检查代替页面消费检查。导航查询通过应用路由观察者绑定当前 PageRoute 与最后一次操作，各自持有加载提示；普通页面离开后即使返回，旧查询仍失效，确认弹窗关闭后可继续处理。观察者保留播放器现有的 Get 路由通知范围。UGC 绑定确认固定账号、视频资料、分 P 和服务配置，只有明确的 404 视为未绑定，待确认写入重试前重新查询。二维码、截图保存和缓存清理按来源与页面交付结果，离页后丢弃迟到提示。原生设备行为仍需专项验收，全仓检查尚未完成。
