# 设置生效时机

媒体加载由 `PlaybackSession` 管理，原生资源由 `NativePlaybackRuntime` 持有。切源可以复用当前播放器，设置的生效时机以会话、媒体加载或播放器重建为准。

| 设置 | 行为与生效时机 |
| --- | --- |
| 手动播放前预加载视频 | 关闭自动播放时提前加载并暂停在续播位置；关闭后解析来源并等待点击。每次查询完成时读取当前设置 |
| 自动播放、自动全屏、自动退出全屏 | 页面和播放动作读取最新偏好；预加载保持暂停意图 |
| 后台播放、点播弹幕开关 | 设置页同时更新当前播放器状态 |
| 不保存播放器内的临时调整 | 播放器中的播放顺序、画中画、后台播放等调整继续在当前会话生效，开启时不写入默认偏好；弹幕和字幕独立保存 |
| 视频缓存策略、缓冲大小、缓冲时长 | 下一次媒体加载生效；默认均衡，前向预算按策略为基准 ×1/×4/×8，后向始终为基准。独立音视频分别受限；时长按倍速转换，直播使用独立策略。详情见[视频缓存](../guides/playback.md#视频缓存) |
| 视频同步、音频时钟平滑 | 捕获到媒体计划，下一次媒体加载生效 |
| Android 音频输出后端 | 选择 OpenSL ES、AAudio、AudioTrack 的尝试顺序；重新创建播放器时生效 |
| Android 纹理缩放 | 输出尺寸策略读取当前设置，随后准备媒体输出时应用 |
| 超分辨率 | 默认档位用于番剧，其他视频可在播放器选择；根据源视频和屏幕分辨率判断可用性。Windows 需要重建输出时会短暂重载媒体，恢复点播位置并保留播放意图 |
| 解码器测试 | 每个编码与解码模式使用独立播放会话，沿用平台输出修正；软件基线只更换解码器。通过要求实际编码、后端、播放推进与纹理消费均得到确认，回退单独标记，不判断颜色与最终画质 |
| 弹幕帧率 | Android 可选跟随屏幕、60、90、120 FPS，旧 30 FPS 设置按跟随屏幕生效；Windows 跟随屏幕。修改后当前弹幕立即更新且保留显示实例 |
| 弹幕密度、固定速度、固定转滚动、轨道间距 | 作用于窗口编排与呈现几何；配置交接保留活动弹幕资源 |
| 会员彩色弹幕、合并及合并字号 | 当前来源刷新规则与显示内容；不重新获取播放器 |
| 禁用“收到的赞”入口和角标 | 消息页入口禁用，首页未读数排除赞；已有订阅立即更新 |
| 消息未读类型、未读标记样式 | 控制首页消息角标的汇总分类与表现 |
| 消息接收、关键词屏蔽、联系人设置 | 服务端账号设置，按账号 Session 读写；和本地入口偏好分别管理 |

解码器测试优先选择各编码的 1080p 样本，无该档时选接近的可用档位，结果显示实际尺寸。Windows 每组在独立进程与预览窗口中测试，驱动崩溃只记录该组失败并继续后续组合；Android 预览固定在测试弹窗内。停止后等待测试进程退出或当前会话真正释放，期间不能重新开始；关闭窗口、初始化超时或迟到结果不会把旧会话交给下一组合。子进程只接收本轮样片与视频同步设置，不读取账号或持久化设置，不改写用户的硬解偏好。CPU、工作集统计属于测试所在进程，Android 上其他页面活动会影响比较；GPU 暂不提供。

## 首页推荐

“首页使用app端推荐”在当前推荐页立即切换来源，取消旧请求并从第一页重新读取，保留实际视口容量。后台标签切换来源后先隐藏旧内容，返回时请求新来源。

“保留首页推荐刷新”控制下一次刷新是否合并已看内容；关闭时立即移除历史位置提示。“显示上次看到位置提示”即时切换当前提示。两项均由推荐 provider 观察持久化偏好，设置页和搜索中的设置入口共用，无需重启。

入口与生命周期见[内容发现模块](../../lib/features/content_discovery/README.md)。

## 桌面窗口

“显示窗口标题栏”位于样式设置的“布局与导航”，默认开启，修改后重启应用生效。该设置控制主窗口的自绘标题栏；全屏期间自动隐藏，退出全屏后按设置恢复。独立播放窗口使用自己的窗口控件，启动失败页保留标题栏以提供窗口操作入口。

入口为 `setting/models/style_settings.dart`、`app/app.dart` 与 `app/desktop_title_bar.dart`，布局和浮层约束见[桌面窗口与标题栏](architecture.md#桌面窗口与标题栏)。
