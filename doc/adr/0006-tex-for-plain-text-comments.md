# 在纯文本评论中降级呈现 TeX

评论编辑器输出纯文本 Unicode，不试图完整执行 TeX，也不依赖接收端有公式渲染器。只替换成对的数学区段；结构错误时保留该区段的原文并报告警告，其他有效区段仍可转换。遇到未知宏时保留宏名和渲染后参数，报告警告；无参数时用空格避免和后续文字粘在一起。解析器将未转义的配对符号当作组边界，转义括号保留为字面量。

上下标按书写顺序嵌套，未分组参数只绑定一个原子；可用的 Unicode 上下标直接显示，不存在的字母或数字保留 `^(...)` / `_(...)` 形式，普通符号维持原样。去除 TeX 命令的分隔空格时保留易读的符号和运算符间距。`\Alpha` 是编辑器接受的非标准近似，输出普通 `A`；Unicode 数学字符集的缺位和数字覆盖范围由字形表处理，不假定连续偏移对所有字符都成立。

单行矩阵保持紧凑；多行矩阵按渲染后的单元格宽度补齐列，再绘制外框。用 figure space 而不是普通空格对齐，因为评论端会折叠普通空白。入口见 [`latex_to_unicode.dart`](../../lib/core/text/latex_to_unicode.dart) 和 [`latex_unicode_data.dart`](../../lib/core/text/latex_unicode_data.dart)。
